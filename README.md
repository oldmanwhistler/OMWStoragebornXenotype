# Storageborn Xenotype

A race of sentient storage that can help with transporting but not much else. Inspired by [Ikea's Kallax Storageborn mod for Skyrim](https://www.youtube.com/watch?v=0tBlFZsMuO8).

## Features (English)

- Storageborn are disabled from most work types but can transport, clean, caravan, and handle animals because what cat does not love a cardboard box?
- Storageborn gain storage capacity as they age. You can configure the values for each stage.
- Configure the Storageborn body types that match the style of your mod pack.
- Storageborn joiner quest.
