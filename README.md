# Storageborn Xenotype

A race of sentient storage that can help with transporting but not much else. Inspired by [Ikea's Kallax Storageborn mod for Skyrim](https://www.youtube.com/watch?v=0tBlFZsMuO8), D&D mimics and the Luggage from Discworld.

![Splash](https://github.com/oldmanwhistler/OMWStoragebornXenotype/blob/main/Images/splashpage.png?raw=true)

## Features (English)

- Storageborn are disabled from most work types but can transport, clean, caravan, and handle animals. What cat does not love a cardboard box?
- Storageborn gain storage capacity and natural armour as they age.
- Configure the storageborn body types to match the theme of your Rimworld game.
