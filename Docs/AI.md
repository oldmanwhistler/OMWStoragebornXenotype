# AI Disclosure

## How AI was used

"Storageborn Xenotype" uses a combination of [Modmixer](https://modmixer.com/) (with GPT-5.6 Luna) and VS Code for manual diffing/coding.

Visual assets generated using GPT-5.6 Luna.
